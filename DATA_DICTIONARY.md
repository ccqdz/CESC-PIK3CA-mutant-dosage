# Data dictionary

## TCGA-CESC derived objects

### `master_tcga_cesc.rds`
Patient-level locked TCGA-CESC cohort (n=178).

Key fields used downstream include patient identifier, mutation status, WGD/ploidy context, chromosome 3q status, and HPV annotations when available.

### `pik_final_tcga_cesc.rds`
Patient-level PIK3CA-mutant TCGA-CESC cohort (n=47).

Key analysis fields:
- `tumor_vaf`: TCGA mutation VAF stored as percent (0–100)
- purity
- ploidy
- local PIK3CA total CN
- WGD status
- chromosome 3q arm call
- major/minor allele-specific copy number

Derived fields are regenerated by the analysis script rather than trusted from a prior workspace.

### `hpv_patient_tcga_cesc.rds`
HPV-characterized subset (n=51). This is an annotation subset, not a complete HPV-positive/negative classification for all 178 TCGA tumors.

### `msk_sample_master.rds`
Patient-level MSK cervical cancer cohort (n=177).

Key fields:
- `patient_id`
- `sample_id`
- histology / grouped histology
- `pik3ca_mut`
- `pik3ca_cna`
- `pik3ca_state`

### `msk_pik_mut.rds`
PIK3CA mutation-event table from MSK (50 mutation events).

## Important interpretation rules

1. Blank HPV annotation outside the 51-case source subset is **not** interpreted as HPV-negative.
2. Bulk sequencing does not directly phase mutation to the major/minor homolog.
3. MSK CNA=2 is reported as a discrete high-level CNA call and is not treated as an ABSOLUTE-equivalent continuous amplification measurement.
